# 🎮 GameVault — Коллекция игр

Desktop-приложение на Python + Tkinter + MySQL для учёта личной коллекции видеоигр.

## 📋 Возможности

- **CRUD** — добавляй, редактируй, удаляй игры
- **Поиск** по названию и студии
- **Сортировка** по 6 полям (title, year, rating, hours, genre, status)
- **Обложки** — превью + полноэкранный просмотр
- **3 доп. функции:**
  - Прогресс прохождения (шкала %)
  - Статистика коллекции (часы, рейтинг, топ-5)
  - Wishlist — список «хочу купить»

## 🛠 Стек

- Python 3.13
- Tkinter (GUI)
- MySQL (БД)
- Pillow (изображения)
